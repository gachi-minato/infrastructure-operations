# インフラ運用保守・サブリード（150社以上）

## 概要
150社以上のオンプレミス/AWS/Azure混在環境における
基盤システム構築・運用保守と情報システム部門の
インフラ支援を担当。
サブリードとして19名チームの管理も兼務しました。

## プロジェクト規模
| 項目 | 内容 |
|---|---|
| 期間 | 2022年5月 〜 2024年1月（約1年8カ月） |
| 担当顧客数 | 150社以上 |
| チーム規模 | リード1名 / 保守メンバ4名 / オペレーター15名 |
| 役割 | サブリード |

## 使用技術
- **OS**：Windows Server / Linux
- **環境**：AWS EC2 / EntraID / VMware ESXi / オンプレミス
- **ネットワーク**：YAMAHAルーター / 無線AP / FortiGate
- **セキュリティ**：Trend Micro Apex One
- **ツール**：Apache / IIS / NAS / VBSS
- **管理**：Active Directory / Office365 / VPN

## 担当業務
- 案件・インシデント・障害・問い合わせ対応
- 運用保守・定点監視・アラート対応・定期保守
- 障害対応（現地調査・夜間対応含む）
- 顧客折衝・新規機器リプレースの提案・プレゼン
- サーバー／ネットワーク増設構築
- サブリードとして進捗管理・タスク分担・課題フォロー
- 新人教育・オペレーター指導

## 構築・保守対応実績
- Windows Server（AD・ファイルサーバー）新規構築
- 仮想サーバー（VMware ESXi・Rocky Linux）構築・保守
- AWS EC2/VPCサーバー構築（DNS・ストレージ・NW設定）
- SSL証明書更新
- Trend Micro Apex One サーバー構築・エージェント配信
- Office365管理・ドメインアカウント管理
- バッチファイル改修による運用改善・自動化

## 成果
- 150社以上のシステム保守で障害発生時の
  迅速な原因特定と復旧対応を実現
- サブリードとして19名チームの進捗管理・
  タスク分担を担当し安定したサービス提供体制を構築
- 顧客先での障害対応・新規機器リプレース提案経験で
  顧客折衝力を強化

## 期間
2022年5月 〜 2024年1月
